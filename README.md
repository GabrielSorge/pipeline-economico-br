# Pipeline de Monitoramento Econômico Brasileiro

## Objetivo
Construir um pipeline de dados que extrai, transforma e disponibiliza indicadores
econômicos brasileiros (câmbio, Selic, IPCA, população) a partir das APIs públicas
do Banco Central do Brasil e do IBGE, evoluindo de um script simples para um
pipeline orquestrado, testado e documentado.

## Motivação
Projeto integrador da minha jornada de estudos em Engenharia de Dados — aplica
progressivamente os conceitos de Python, SQL, consumo de APIs, ETL/ELT e
orquestração (Airflow).

## Fontes de dados
- Banco Central do Brasil (dadosabertos.bcb.gov.br) — séries econômicas (câmbio, Selic)
- IBGE (servicodados.ibge.gov.br) — dados populacionais e municipais
